# DemoLand

**DemoLand** is a dynamic shooter game where your reaction and tactics determine the outcome of battles. Fight on unique maps, hone your skills, and become a legend of the arena!

---

## 📌 Features

- **Dynamic Gameplay:** Fast-paced shooter with unique maps.
- **Futuristic Arsenal:** A variety of weapons to choose from.
- **Character Customization:** Personalize your character.
- **Multiple Game Modes:** Engaging and diverse gameplay.
- **Anti-Cheat System:** Fair play for everyone.

## 📂 Project Structure

```

│── img/                  # Game images (maps, skins, etc.)
│   ├── logo.ico          # Gameplay screenshot
│   ├── maps.jpg         # Character skins
│   |── skins.jpg      # Telegram promo image
│   └── telegram.png      # Telegram promo image
│── index.html            # Main HTML file
└── style.css             # Styling for the website
```

---

## 🚀 How to Run

1. **Clone the repository:**
   ```bash
   git clone https://github.com/platilich/demoland.git
   ```

2. **Open `index.html` in your browser:**
   - Simply double-click the file or use a local server for development.

---

## 🎨 Customization

- **Images:** Replace files in the `img/` folder with your own assets.
- **Styling:** Edit `style.css` to change colors, fonts, and layout.
